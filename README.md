# 🎬 وب‌سایت فیلم

این پروژه یک وب‌سایت نمایش و معرفی فیلم است که با استفاده از **HTML**، **CSS** و **JavaScript** طراحی و پیاده‌سازی شده است. در این پروژه از کتابخانه **Swiper.js** برای ایجاد اسلایدرهای حرفه‌ای و روان استفاده شده و طراحی آن به صورت **کاملاً ریسپانسیو** انجام شده است تا در دستگاه‌های مختلف تجربه کاربری مناسبی ارائه دهد.

## ✨ امکانات

- طراحی مدرن و جذاب
- نمایش فیلم‌ها در اسلایدرهای حرفه‌ای با **Swiper.js**
- رابط کاربری روان و کاربرپسند
- دسته‌بندی فیلم‌ها
- افکت‌ها و تعاملات با JavaScript
- منوی ناوبری
- طراحی کاملاً ریسپانسیو برای موبایل، تبلت و دسکتاپ
- اسکرول و انیمیشن‌های نرم

## 🛠️ تکنولوژی‌های استفاده شده

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Swiper.js

## 📱 ریسپانسیو

این پروژه به صورت **کاملاً ریسپانسیو** طراحی شده و در اندازه‌های مختلف صفحه‌نمایش، از جمله موبایل، تبلت و دسکتاپ، به‌درستی نمایش داده می‌شود.

## 🎯 هدف پروژه

هدف از توسعه این پروژه، تقویت مهارت‌های فرانت‌اند، پیاده‌سازی رابط کاربری مدرن، کار با کتابخانه **Swiper.js** و تمرین طراحی وب‌سایت‌های ریسپانسیو بوده است.

## 🚀 نحوه اجرا

1. پروژه را دانلود یا Clone کنید.
2. فایل `index.html` را در مرورگر اجرا کنید.

## 📄 توضیحات

این پروژه با هدف آموزشی و تکمیل نمونه‌کار (Portfolio) طراحی و پیاده‌سازی شده است.
